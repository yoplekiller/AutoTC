## 1. 기능 개요 및 목적
본 기능은 크림의 스타일 탭에서 사진 등록을 개선하는 것을 목표로 한다. 사용자는 최대 5장의 사진을 다중 업로드할 수 있으며, 사진의 순서를 변경하는 드래그 기능을 추가로 지원한다. 등록이 완료되면 스타일 피드에 즉시 반영된다. 이러한 개선은 사용자의 편의성을 높이고 사진 등록 및 管理을 효율적으로 하도록 설계되었다.

## 2. 화면 흐름
1. **시작**: 사용자가 스타일 탭에 접근하여 사진 등록 버튼을 클릭한다.
2. **사진 선택**: 사용자는 최대 5장의 사진을 선택할 수 있다. 선택된 사진은 미리보기로 표시된다.
   - 버튼: "사진 추가", "등록"
   - 입력 필드명: 없음
3. **사진 순서 변경**: 사용자는 드래그 앤 드롭으로 사진의 순서를 변경할 수 있다.
   - 버튼: 없음
4. **등록 완료**: 사용자가 등록 버튼을 클릭하면 선택된 사진이 서버로 업로드된다.
   - 버튼: "등록"
5. **등록 결과**: 사진 등록이 성공적으로 완료되면 사용자는 스타일 피드에서 즉시 반영된 사진을 확인할 수 있다.

## 3. 입력값 유효성 규칙
- **사진 파일 형식**: JPG, PNG만 지원한다. 다른 형식의 파일을 업로드 시도할 경우 "지원하는 파일 형식은 JPG, PNG입니다."라는 에러 메시지가 표시된다.
- **사진 파일 크기**: 5MB 이하 파일만 업로드 가능하다. 5MB 초과 시 "최대 5MB까지 업로드가 가능합니다."라는 에러 메시지가 표시된다.
- **사진 개수**: 1장에서 5장까지 선택할 수 있다. 0장 선택 시 "최소 1장의 사진을 선택해주세요."라는 에러 메시지가 표시되고, 6장 이상 선택 시 "최대 5장의 사진만 업로드할 수 있습니다."라는 에러 메시지가 표시된다.

## 4. 핵심 정책
- **최대 업로드 파일 수**: 5장
- **최대 파일 크기**: 5MB
- **지원 파일 형식**: JPG, PNG
- **登録 완료 후**: 즉시 반영

## 5. 예외/에러 케이스
1. **사진 파일 형식 에러**: 사용자가 지원하지 않는 파일 형식을 업로드 시도할 경우.
   - 에러 메시지: "지원하는 파일 형식은 JPG, PNG입니다."
2. **사진 파일 크기 초과**: 사용자가 5MB이상의 파일을 업로드 시도할 경우.
   - 에러 메시지: "최대 5MB까지 업로드가 가능합니다."
3. **0장 선택**: 사용자가 사진을 하나도 선택하지 않고 등록 버튼을 클릭할 경우.
   - 에러 메시지: "최소 1장의 사진을 선택해주세요."
4. **6장 이상 선택**: 사용자가 6장 이상의 사진을 선택하고 등록 버튼을 클릭할 경우.
   - 에러 메시지: "최대 5장의 사진만 업로드할 수 있습니다."
5. **네트워크 오류**: 사용자가 사진을 업로드 중 네트워크가 끊길 경우.
   - 에러 메시지: "네트워크 오류로 업로드에 실패했습니다. 다시 시도해주세요."
6. **서버 오류**: 사용자의 사진을 서버에서 처리하다 오류가 발생할 경우.
   - 에러 메시지: "서버 오류로 업로드에 실패했습니다. 다시 시도해주세요."
7. **중복된 파일 이름**: 사용자가 동일한 이름의 파일을 여러 개 업로드 시도할 경우.
   - 에러 메시지: "동일한 이름의 파일이 이미 업로드되었습니다."
8. **기존 파일과 동일한 파일 업로드**: 사용자가 기존에 업로드된 파일과 동일한 파일을 업로드 시도할 경우.
   - 에러 메시지: "이미 업로드된 파일입니다."
9. **드래그 기능 오류**: 사용자가 사진 순서를 변경하는 도중 오류가 발생할 경우.
   - 에러 메시지: "사진 순서 변경에 실패했습니다. 다시 시도해주세요."
10. **등록 완료 후 즉시 반영 실패**: 사용자가 등록을 완료했지만 스타일 피드에 즉시 반영이 실패할 경우.
    - 에러 메시지: "등록은 완료되었지만 피드 반영에 실패했습니다. 다시 시도해주세요."
11. **로딩 시간초과**: 사진 업로드 시 로딩 시간이 너무 길어지는 경우.
    - 에러 메시지: "업로드에 시간이 너무 걸립니다. 네트워크 상태를 확인하세요."
